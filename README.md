CustomMechStorage v1.0.0

CustomMechStorage is a BattleTech/RogueTech mod that allows you to store and later restore
customized BattleMechs without losing their individual configuration.

What Does It Do?

In BattleTech, a customized 'Mech can be more than just its chassis and variant.
You may have spent time changing its weapons, equipment, armor, ammunition, and
other components to create a specific configuration.

CustomMechStorage preserves that actual assembled 'Mech when you store it.

When you later bring the 'Mech back into an active 'Mech bay, the MOD
restores the preserved configuration rather than simply creating a stock version
of the chassis.

Example

You have a customized Commando.

You:

Customize the Commando.
Store it.
Later decide you want to use it again.
Pull the Commando back into the 'Mech bay.

The Commando returns with its equipment and loadout intact.

That's the basic purpose of CustomMechStorage.

Features
Store customized BattleMechs
Preserve the individual 'Mech configuration
Restore stored 'Mechs with their equipment intact
Works with the existing BattleTech 'Mech Lab readying process
Preserves normal Scrap functionality
Allows normal Scrap for Parts functionality
What CustomMechStorage Does NOT Do

CustomMechStorage does not replace or redesign the BattleTech 'Mech Lab.

It is intended to add one specific capability:

Store the 'Mech you actually built and get that same configuration back later.

Normal BattleTech/RogueTech functionality remains available, including scrapping 'Mechs for parts.

Installation
Download CustomMechStorage.v.1.0.0.zip.
Extract the CustomMechStorage folder.
Place the folder in your BattleTech Mods directory.

Your installation should look like:

BATTLETECH
└── Mods
    └── CustomMechStorage
        ├── CustomMechStorage.dll
        ├── mod.json
        └── modstate.json
Start BattleTech/RogueTech.
Requirements

BattleTech with RogueTech

CustomMechStorage was developed and tested with RogueTech.

Because RogueTech changes and extends BattleTech's MechLab and game systems,
compatibility with other BattleTech mod configurations has not been independently tested.
